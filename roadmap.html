MediNet 2.0.1 RoadmapWhat is available and what remains planned

The revised workspace, API v2 and Node privacy-budget workflows are already in the reviewed snapshots. Future work is listed separately, with no unverified delivery dates.

Version scope

Pinned implementation, not a branch roadmap

This 2.0.1 guide uses the Hub snapshot f09bb753 and the companion Node snapshot 5e52ac5, merged on 7 July 2026. The Node repository has no independently named 2.0.1 tag; these instructions pin the reviewed commits. See the version comparison for scope and sources.

The v1 roadmap mixed future ideas, implemented features and dated targets. This edition moves verified features into “Available in this snapshot” and identifies future work from the pinned repository documents. The stable v1 roadmap preserves the earlier plan.

A planned item below means it was documented as future work; it does not assert that development is currently active or promise a release date.

Historical plans can lag behind the source

The pinned Hub README still describes the designer as sequential-only, although the source also contains an advanced-designer route. The Node's earlier v2 technical notes describe SVM support-vector export and simple budget checks; the pinned code instead implements DP-SGD FedSVM weights and in-flight budget admission. This documentation follows the reviewed code and labels unverified future work explicitly.
