1.0 → 2.0.1

Documentation changes, verified capabilities and the exact source snapshots.

Version scope

The default site documents the 2.0.1 snapshot requested for this review. The version selector opens the stable 1.0 documentation without overwriting its content or screenshots.

The local checkout is named MediNetHub-2.0.1; its README still uses v0.2 and its commit is a merge of v0.2. This documentation retains the requested 2.0.1 label and records exact commits below. It does not infer a release tag from the directory name. No 2.1 branch changes are included.

The comparison is between the original documentation saved in this repository and the reviewed source snapshot. It is not a claim that every capability first appeared in an official 2.0.1 release.

Features that must not be presented as complete

  • Model Studio’s Import button only displays “coming soon”.
  • Automatic grid search and the experiment detail demonstration do not establish a working experiment expansion/comparison service.
  • FedProx and Flower version menu entries do not establish backend strategy/runtime switching.
  • General medical-imaging, time-series and genomic ingestion are not established by layer options.
  • Advanced graph and recurrent corrections from development branch 2.1 are excluded.
  • No source review establishes GDPR/HIPAA certification, guaranteed accuracy gains or secure aggregation.
  • The Datasets page’s connection-expiry refresh calls an out-of-scope getCookie helper in this snapshot; a missing badge does not establish a valid key.
  • Some client-dashboard timing/trend fields and performance-history endpoints are placeholders or random synthetic history; they are not measurements.

Case-study data schema: the bundled CSV has 53 columns including an unnamed exported index and the Heart Attack Risk target. The historical paper configuration uses 52 inputs; excluding both index and target yields 51 predictors. A new run must match preprocessing and input dimensions across Nodes.

All renewed screenshots use synthetic demonstration contexts rendered through the original Hub templates. They show the interface, not a completed real federation or clinical result.
